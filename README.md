# Vilye Farmer Producer Company

Website for **Vilye Farmer Producer Company Limited**, a farmer-led organization based in Ratnagiri, Maharashtra. Vilye FPC brings farmers together to build stronger market access, share resources, and create a more secure and prosperous farming future.

**👉 Visit [vilyefpc.com](https://vilyefpc.com)**

## Stack

- [Astro](https://astro.build) — static site
- [Tailwind CSS 4](https://tailwindcss.com) — via `@tailwindcss/vite`
- [Vite+](https://viteplus.dev) — unified toolchain (`vp` CLI)
- [pnpm](https://pnpm.io) — package manager

## Commands

| Command          | Purpose                      |
| ---------------- | ---------------------------- |
| `vp install`     | Install dependencies         |
| `vp run dev`     | Start the development server |
| `vp run build`   | Build the production site    |
| `vp run preview` | Preview the production build |
| `vp check`       | Format, lint, and type check |

## Deployment

Pushing to `main` deploys the site automatically to GitHub Pages through GitHub Actions. The workflow is also available to run manually from the Actions tab.
